Доступ користувача до інших функцій регулюється [вбудованою системою аутентифікації](https://docs.djangoproject.com/en/3.2/topics/auth/default/) Django. Коли екземпляр створено, `initdb` код створює набір дозволів, які надаються групам. За замовчуванням, усі нові користувачі призначаються в групу `редакторів`, що дозволяє їм редагувати метадані книг.

Адміністратор екземплярів має мати статус `суперкористувача`, що надає їм доступ до адміністратора Django (`/адміністратор`) та всіх дозволів.

## Дозволи та групи
Ця таблиця демонструє чотири групи користувачів (адміністратор, модератор, редактор та користувач) та дозволи якими володіє кожна окрема група:

|                                    | адміністратор | модератор | редактор | користувач |
| ---------------------------------- | ------------- | --------- | -------- | ---------- |
| редагувати налаштування екземпляра | ✔️            | -         | -        | -          |
| змінювати рівень користувача       | ✔️            | -         | -        | -          |
| керувати федерацією                | ✔️            | ✔️        | -        | -          |
| надсилати запрошення               | ✔️            | ✔️        | -        | -          |
| деактивовувати користувачів        | ✔️            | ✔️        | -        | -          |
| видаляти пости                     | ✔️            | ✔️        | -        | -          |
| редагувати книги                   | ✔️            | ✔️        | ✔️       | -          |
